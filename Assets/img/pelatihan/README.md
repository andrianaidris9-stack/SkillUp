# Ilustrasi Kategori Pelatihan

Delapan ilustrasi SVG ini adalah gambar bawaan lokal untuk kartu katalog dan detail program. Semua memakai gaya visual, ukuran kanvas, dan palet warna SkillUp yang sama.

| File | Kategori |
|---|---|
| `kecantikan.svg` | Kecantikan dan Tata Rias |
| `kuliner.svg` | Kuliner dan Tata Boga |
| `teknik.svg` | Teknik dan Alat Berat |
| `busana.svg` | Tata Busana dan Kerajinan |
| `administrasi.svg` | Administrasi dan Teknologi |
| `kelistrikan.svg` | Kelistrikan dan Keterampilan Teknik |
| `pariwisata.svg` | Pariwisata dan Perhotelan |
| `kewirausahaan.svg` | Kewirausahaan |

Gambar program yang diunggah Admin dapat menggantikan ilustrasi bawaan. Pada prototipe Tahap 4, gambar unggahan disimpan sebagai data URL di browser. Pada Tahap 5, file perlu disimpan di server dan database hanya menyimpan alamat/path file.
