# Catatan Struktur SkillUp

Folder utama dikelompokkan berdasarkan peran dan fungsi, bukan nomor tahap. Halaman publik berada di `Beranda`, `Tentang`, `InformasiPelatihan`, dan `DetailPelatihan`. Autentikasi berada di `Autentikasi`. Modul Admin dan Peserta berada di folder masing-masing. Algoritma dan dataset dipisahkan dari data operasional. Aset bersama dan skrip lintas halaman berada di `Assets` dan `Shared`.

Setiap halaman aktif memiliki HTML, CSS, dan JavaScript terpisah sesuai kebutuhan. Komponen layout Admin dan Peserta menggunakan stylesheet bersama untuk menjaga konsistensi.
